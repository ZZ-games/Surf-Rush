# Surf Rush

An endless neon surf game for the browser. Drop in, carve the turns, hop the bars, smash glass walls, grab coins, and unlock new balls from mystery boxes.

**Play:** open `index.html` in a browser (or enable GitHub Pages on this repo).

## Controls

| Key | Action |
| --- | --- |
| A / D (or ← / →) | Steer |
| Space | Hop |
| W / S | Faster / slower |
| Esc | Menu |
| M | Sound on/off |

On phones and tablets, on-screen Left, Right and Hop buttons appear automatically.

## Files

- `index.html` – the whole game (three.js from a CDN)
- `logo.webp` – menu logo art
- `icon.png` – browser tab icon

Progress (best distance, coins, unlocked balls) is saved in the browser's localStorage.
